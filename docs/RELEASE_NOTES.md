Reproducibility package for “Grouped Proportional Hazards under Coarse Time: Information Loss and Baseline Estimation,” by Simhaa T. T. and Sudheesh Kumar Kattumannil.

Includes frozen aggregate outputs, original experiment code, dataset acquisition notes, numerical provenance, and offline regeneration of the main figures and tables. Third-party raw datasets are not redistributed. Run `python scripts/reproduce_main_results.py` to rebuild and verify the aggregate deliverables.

Before using these notes for publication, resolve the release checklist and describe any retained limitations explicitly, including missing original simulation hash seed, dataset cache provenance and editable supplement source. This is an unreleased draft; no claim of a clean full experimental rerun is made.
